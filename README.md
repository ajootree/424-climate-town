# 다섯 마을 수호대 — 햇살마을

초등 과학 「기후변화와 우리 생활」을 바탕으로 한 무광 동화풍 2D 횡스크롤 RPG입니다. 삽화 도입부와 첫 마을의 퀘스트 5개, 보스, 첫 수호석 엔딩까지 플레이할 수 있습니다.

게임 실행: https://ajootree.github.io/424-climate-town/

소스 저장소: https://github.com/ajootree/424-climate-town

GitHub Pages 최초 설정: 저장소 Settings → Pages → Source를 Deploy from a branch, Branch를 main, 폴더를 / (root)로 선택하고 Save합니다. 이 설정 후 main에 새 커밋을 올리면 게임 페이지가 자동 갱신됩니다. 정적 파일이라 별도 빌드 명령은 필요하지 않습니다.

## 실행과 배포

정적 HTML·JavaScript·이미지로 구성되어 서버 코드, API 키, 로그인, 런타임 의존성 설치가 필요하지 않습니다. GitHub Pages는 main 브랜치의 저장소 루트(/)에서 배포하도록 설정하며, main에 새 변경을 올리면 같은 주소가 갱신됩니다. .nojekyll을 유지합니다.

Vercel과 Cloudflare Pages에도 같은 파일을 배포할 수 있습니다. 별도 빌드 없이 루트 폴더를 정적 출력으로 사용합니다. vercel.json을 포함했습니다.

## 조작

- 태블릿·스마트폰 가로: 원형 조이패드, 공격·점프·스킬·기력 충전·대화 버튼. 이동과 공격 동시 터치를 지원합니다.
- 컴퓨터: 좌우 방향키 또는 A/D, Space 점프, Z 공격, X 스킬, E 대화·조사, Q 기력 충전, Esc 메뉴.
- 기력 문제를 읽는 동안 전투가 멈춥니다. 정답이면 40 회복, 오답이면 힌트를 보고 재도전합니다.
- NPC는 촌장님·배달원·쉼터 선생님·관측소 선생님으로 표시합니다.
- 긴 글을 줄이고 한 줄 목표, 짧은 대사, 상황 그림 선택지를 사용합니다.

모든 배경·캐릭터·몬스터·물품·UI 프레임·터치 버튼은 생성 이미지입니다. Canvas는 이미지 배치와 애니메이션, 입력·충돌·글자·게이지를 처리합니다. CSS로 게임 오브젝트를 그리거나 이모지로 대체하지 않습니다.

진행은 현재 브라우저에 자동 저장됩니다. 다른 기기 또는 도메인으로 저장이 자동 이동하지 않습니다. 읽어주기는 브라우저 내장 음성 합성을 사용하며 한국어 음성 지원은 기기에 따라 다릅니다. 관측판의 6일/12일은 실제 통계가 아닌 게임용 가상 자료로 표시합니다.

## 개발 검사

npm ci 후 npm test, npm run check를 실행합니다. 게임을 실행하는 데 npm은 필요하지 않습니다. 검사에는 상태 단위 7개와 실제 Canvas 엔진·생성 이미지·키보드·조이패드·동시 터치·퀘스트 5개·기력 충전·보스·엔딩 통합 검사 1개가 포함됩니다. 화면 렌더링은 PC 1280×720, 태블릿 1024×768, 스마트폰 가로 932×430으로 확인합니다. 실제 모바일 기기의 입력·오디오·성능은 별도 확인이 필요합니다.

첫 마을은 15~20분을 목표로 설계했으며 실제 학생 플레이 시간은 아직 측정하지 않았습니다.

## 단독 HTML 내보내기

node scripts/export-offline.mjs standalone.html 명령으로 이미지까지 포함한 한 개의 HTML을 만듭니다. 원본 이미지와 게임 소스는 수정하지 않습니다. 로컬 HTML 실행 가능 여부는 기기 브라우저와 파일 앱 정책에 따라 다릅니다.
